# 假屏保（Windows）

这是一个轻量的隐私屏幕遮罩：电脑全局键盘/鼠标闲置达到设定时间后，全屏显示图片，后台程序和下载不会暂停；再次移动鼠标或按任意键即可恢复。

## 运行

普通使用直接下载并双击 `YinMu-Privacy-Screen.exe`，不需要安装 Python。源码运行方式：安装 Python 3.10+ 后双击 `run.vbs` 或 `run.bat`。

## 功能

- 闲置时间 1–1440 分钟可调，默认 30 分钟。
- 支持选择 PNG/JPG/JPEG/WEBP 图片；每个物理显示器使用独立遮罩窗口。
- “立即预览”可验证真实多显示器效果；移动鼠标或键盘输入退出。
- 内置一张由 AI 生成的深色隐私屏保，也可随时更换自己的图片。
- 设置页可选择是否随 Windows 登录自动启动。

主界面采用现代化侧边导航，包含总览、自动隐藏、屏保画面、显示器和设置页面。每个物理显示器创建独立遮罩，并按自身分辨率独立裁剪图片。

设置保存在程序目录的 `settings.json`。
